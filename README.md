# Paradise Nursery 🌿

A responsive online plant shop built with React. Browse indoor plants, view product details, add plants to a shopping cart, adjust quantities, and see the total update automatically.

## Features
- Welcome landing page with a plant-themed hero section
- Plant catalog with images, descriptions, prices, and categories
- Add-to-cart functionality
- Increase/decrease item quantities and remove items
- Dynamic cart subtotal and item count
- About Us section
- Responsive layout for desktop and mobile

## Tech Stack
- React
- JavaScript
- CSS

## Run locally
1. Install Node.js (LTS) from https://nodejs.org/
2. Open a terminal in this project folder.
3. Run `npm install`
4. Run `npm start`
5. Open the local address shown in the terminal (usually http://localhost:3000).
